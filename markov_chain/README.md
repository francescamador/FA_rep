# Markov chain

MArkov chain analisys

## What it does

Downloads a specified number of paragraphs from lorem-api, stripts anything that is not a letter [a-z, A-Z], and counts the number of transitions from vowel-to-vowel, vowel-to-consonant, consonant-to-consonant, and consonant-to-vowel.

## Prerequisites

- Python 3.10+

# Run

```bash
python markov_chain.py
```
